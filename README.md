# SQL Sales Analysis Project (PostgreSQL)

## Project Overview
This project analyzes sales data using PostgreSQL to generate useful business insights about revenue, products, customers, and cities.

## Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

## SQL Concepts
- SELECT and WHERE
- ORDER BY and LIMIT
- Aggregate functions: SUM, COUNT, AVG
- GROUP BY and HAVING
- CASE WHEN
- INNER JOIN

## Business Analysis
- Calculated total revenue and average order value
- Analyzed product-wise revenue
- Compared city-wise sales
- Analyzed customer orders and spending

## Dataset
A small, synthetic dataset created for SQL practice and learning.

## Key Findings
- Total revenue: ₹104,000
- Total orders: 5
- Average order value: ₹20,800
- Highest-revenue product: Laptop

## How to Run
1. Open PostgreSQL using pgAdmin 4.
2. Open the `sales_analysis.sql` file.
3. Connect to the database containing the project tables.
4. Execute the queries to view the results.
